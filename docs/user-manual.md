# User Manual

## Getting Started

### Login

1. Navigate to the platform URL
2. Enter your email and password
3. Click "Sign In"
4. You will be redirected to the Dashboard

### Dashboard Overview

The dashboard displays key metrics:
- **Total Emissions**: Combined Scope 1, 2, 3 in tCO2e
- **Scope Breakdown**: Individual scope totals
- **Reduction Progress**: Progress toward reduction targets
- **Emission Intensity**: Emissions per revenue unit
- **Trend Charts**: Monthly and annual comparisons

## Managing Emission Records

### Adding a New Record

1. Navigate to Emissions > click "+ New Record"
2. Select the Scope (1, 2, or 3)
3. Choose the Source Type (combustion, fugitive, etc.)
4. Select Fuel/Source type
5. Enter Activity Data (amount and unit)
6. Click "Calculate Emissions" for automatic calculation
7. Upload supporting evidence (invoices, meter readings)
8. Click "Submit for Approval" or "Save as Draft"

### Viewing Records

1. Go to "Emissions" in the sidebar
2. Use filters to narrow results (scope, site, period, status)
3. Click on a record to view details
4. Sort columns by clicking headers

### Approval Workflow

Records go through these stages:
1. **Draft** - Created but not submitted
2. **Pending** - Submitted, awaiting reviewer approval
3. **Approved** - Verified and accepted
4. **Rejected** - Returned with feedback

## Emission Factors

### Browsing the Library

1. Navigate to "Emission Factors"
2. Search by name or filter by provider
3. View factor details including source and version
4. Compare different provider versions

### Available Providers

- **Korea MOE 2023**: Korean Ministry of Environment (default for Korean operations)
- **IPCC 2006**: International default factors
- **DEFRA 2023**: UK government factors (useful for Scope 3)

## Generating Reports

### Creating a Report

1. Go to "Reports"
2. Select report type (ISO 14064, CDP, GRI, Custom)
3. Choose reporting period
4. Select scopes to include
5. Click "Generate Report"
6. Download when generation is complete

### Report Types

- **ISO 14064**: Full GHG inventory for third-party verification
- **CDP**: Climate Disclosure Project questionnaire data
- **GRI 305**: GRI Standards emissions disclosure
- **Custom**: Internal reporting with flexible format

## Supplier Portal

Suppliers can be managed for Scope 3 calculations:
1. Navigate to "Suppliers"
2. Add supplier details
3. Request emission data from suppliers
4. Use supplier data in Scope 3 calculations

## Workflow Approval

### For Reviewers

1. Navigate to "Emissions" and filter by "Pending" status
2. Click on a record to review
3. Check calculation details, evidence, and notes
4. Click "Approve" or "Reject" with reason
